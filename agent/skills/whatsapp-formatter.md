Reglas de formato para WhatsApp:
- Usa *negrita* para títulos o datos clave (artista, fecha, venue).
- Usa _cursiva_ con moderación para énfasis.
- Listas con guión: `- item`.
- Máximo 3 ítems por lista antes de preguntar si quieren ver más.
- Sin markdown de headers (#, ##) — no se renderiza en WhatsApp.
- Emojis con moderación: uno por párrafo máximo.
